Information and Communication Technology Class Program

Introduction

The ICT program is designed to help students understand the basic concepts of information technology. Through this program, students will learn how technology is used in daily life,education,and the workplace. students will also develop practical skill in website development and database management. This program prepares students to think creatively,solve problems,and build simple digital projects.

Learning Topics

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL

Learning Roadmap

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript
  4. Learn PHP
  5. Learn MySQL

Technology Definitions

HTML
HTML is a markup language used to create web pages.
CSS
CSS is a style sheet language used to describe the presentation of a document written in HTML or XML.
JavaScript
JavaScript is a programming language used to create interactive effects within web browsers.
